# Gtuner v0.1.0 — first public preview

Gtuner is an offline practice companion for Android 11 and newer. The app is an early preview, not a Play Store release.

- **Live Jam:** A scrolling pitch-dot graph, recurring note names, and estimated BPM.
- **Tuner:** A smoothed cents needle, adjustable A4 reference, mic sensitivity, and graph dot-size controls.
- **Practice recording:** AAC by default or lossless WAV, saved locally to `Music/`. Play back a take in Jam with pitch and tempo analysis, seeking, and bookmarks.
- **Documentation:** The [illustrated user guide](https://github.com/balbgied/Gtuner/blob/v0.1.0/docs/USER_GUIDE.md) explains every main control and the app’s permissions.

## Downloads

- `Gtuner-v0.1.0.apk` — installable Android preview APK (debug-signed).
- `Gtuner-v0.1.0.apk.sha256` — SHA-256 checksum for the APK.
- **Source code** — GitHub’s archives for the matching `v0.1.0` tag. See the repository README for build instructions and the GPLv3 license.

On Android, open the downloaded APK to install it. If an existing Gtuner build was signed with a different key, Android will not install the update over it. Before uninstalling an old build, back up any recordings you want to keep; uninstalling clears in-app settings and bookmarks.
