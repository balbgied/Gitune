# Gitune v0.1.1 — new name

Gtuner is now **Gitune**. This update changes the Android launcher name, the prefix on new recordings, and the documentation. Existing recordings are not renamed. Gitune is still an offline Android 11+ preview, not a Play Store release.

- **Live Jam:** A scrolling pitch-dot graph, recurring note names, and estimated BPM.
- **Tuner:** A smoothed cents needle, adjustable A4 reference, mic sensitivity, and graph dot-size controls.
- **Practice recording:** AAC by default or lossless WAV, saved locally to `Music/`. Play back a take in Jam with pitch and tempo analysis, seeking, and bookmarks.
- **Documentation:** The [illustrated user guide](https://github.com/balbgied/Gitune/blob/v0.1.1/docs/USER_GUIDE.md) explains every main control and the app’s permissions.

## Downloads

- `Gitune-v0.1.1.apk` — installable Android preview APK (debug-signed).
- `Gitune-v0.1.1.apk.sha256` — SHA-256 checksum for the APK.
- **Source code** — GitHub’s archives for the matching `v0.1.1` tag. See the repository README for build instructions and the GPLv3 license.

On Android, open the APK to install it. Install it over the original GitHub Gtuner release to keep your settings and bookmarks. If your old build was signed with a different key, Android will not install the update over it. Before uninstalling an old build, back up any recordings you want to keep; uninstalling clears in-app settings and bookmarks.
